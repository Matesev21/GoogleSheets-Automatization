# Google Sheets Automation – Monday.com Replacement

This project was developed to replace a paid task management tool (Monday.com) with a fully customized system built using Google Sheets and Apps Script. The solution reduced company costs and improved transparency across daily team workflows.

## 🎯 Objective

- Replace the $140/month Monday.com subscription.
- Create an automated task tracking system for employees using Google Sheets.
- Provide management with a centralized dashboard to track team progress in real time.

## 🛠️ Technologies & Tools

- Google Sheets
- Google Apps Script (JavaScript-based automation)
- Google Formulas (FILTER, IMPORTRANGE, QUERY, etc.)

## 💡 Implemented Solution

1. **Daily To-Do Spreadsheets for Each Employee**  
   - 5 Google Sheets, one for each employee.
   - Custom script that updates task status and redirects completed tasks to another sheet.

2. **Management Dashboard**  
   - A master spreadsheet that collects data from all employee sheets.
   - Custom Apps Script aggregates tasks and displays them in a filtered, easy-to-read layout.
   - Multiple filtering options (by employee, status, date).

3. **Automation Features**  
   - Real-time updates when tasks are marked complete.
   - Automatic row movement and status change.
   - Synchronized task tracking without manual input.

## 🚀 Outcome

- 100% replacement of Monday.com functionality for daily task tracking.
- Zero-cost custom system tailored to company needs.
- Improved task visibility for both employees and managers.

✅ Fully functional and in active use
